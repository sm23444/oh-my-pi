# 中文自动化变更记录

## [Unreleased]

### Added

- 自动跟随 OMP 官方稳定版，复用已有中文译文并使用可配置模型补译新增界面文案，通过校验后生成中文源码和 Windows 运行包。

### Fixed

- Windows CLI 构建使用独立缓存和文件复制，避免汉化写入影响 Bun 的原始依赖缓存。
- Windows CLI 安装优先使用系统 tar 解压依赖文件，减少安装等待时间。
- Windows 启动器统一写入 CRLF，确保中文目录和空格路径下可直接运行 omp。
- 增量翻译先保存同批合格译文，单独重试未通过变量顺序等校验的文案；返回格式持续不合格时自动拆小批次，并报告具体失败原因。
- 单条译文持续未通过校验时记录原因并继续补译，保存成功进度；未完成翻译仍阻止发布，同一官方版本的进度可在自动化更新后恢复。
